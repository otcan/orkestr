# Public-Safe Console Evidence

The homepage uses the synthetic managed system `Public Opportunity Monitor ·
Daily Run #042`. Every identifier, time, source count, criterion, and state is
illustrative and contains no customer data.

The evidence shows approved public sources checked on a schedule, records
normalized with provenance, deterministic and assisted matching, a human review
queue, recorded decisions, and a digest delivered after review. Controls are
intentionally disabled.

This proof demonstrates the Orkestr operating layer—persistent jobs, schedules,
state, review, history, and recovery—not a finished universal tender product or
customer deployment. It does not claim guaranteed source coverage, eligibility,
matching accuracy, or access to non-public data. Available sources, components,
permissions, and delivery channels are deployment-specific.

The interface remains understandable without animation or JavaScript. A real
deployment screenshot may replace it only with explicit privacy, security,
claims, and publication approval.
