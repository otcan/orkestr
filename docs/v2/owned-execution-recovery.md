# Ordinary server terminal continuation

The private `isolated-acceptance-v1` configuration continues to select one owner,
conversation, machine session and immutable Codex launcher. HTTP never supplies
native identity, provider credentials, a supervisor incarnation or a cleanup
assertion. Unconfigured startup remains disabled.

After browser Stop, Core schema 25 holds every unconsumed owner input through the
exact cancellation boundary. `/api/v2/conversations/{id}/held-inputs` is a bounded,
current-cookie read of the original message/event/sequence and Stop provenance.
It cannot release or delete holds. A newly admitted post-Stop input may wake the
factory; an older held input cannot spend a setup grant or launch a replacement.

Continuation requires both canonical durable `Stopped` evidence and a separate
owned native-tree cleanup witness. The exact stopped pump moves into Runtime's
retirement handle. Only the reviewed broker's EOF cleanup, descendant ECHILD and
owned Child wait with reserved exit 73 produce that witness. ACK-only, timeout,
ordinary exit, forced death and a broker capacity counter do not qualify. Core
then issues one metadata grant for strict resume of the same persisted native
session. The fresh input receives a new consumed dispatch/run, never a replay of
the stopped run. Historical in-process Stop receipts remain inert exact replays.

After owner acceptance, controlled shutdown retires the native tree before
calling Core's sealed graceful-retirement port. Schema 28 records the exact
accepted predecessor and supervisor generation. The same private configuration
can restart immediately using Core's exact predecessor CAS and one-use metadata
grant. Natural lease expiry, legacy deadline zero and unclean crash do not count
as graceful retirement. No clock modification or database reset is used.

This checkpoint qualifies Deep execution without the optional Worker policy.
Worker descendant retirement still requires its own sealed witness; configured
Worker recovery refuses rather than interpreting broker wait as full-tree proof.
A restart that reserves metadata and then shuts down before fresh input requires
reconciliation; the unused one-use grant is not silently reissued. Cross-process
Stop replay remains unavailable without a live registry entry. Authenticated
historical acceptance receipts remain readable/replayable without changing a
successor. General crash recovery and authenticated filesystem/egress isolation
are separate gates.
